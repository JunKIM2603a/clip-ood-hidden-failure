# Novelty Collision Search

Before stating that the proposed gap is novel, search for work at the intersection of VLM OOD detection, subgroup reliability, and prompt sensitivity.

## Search queries

- vision-language OOD worst-group
- CLIP OOD subgroup
- semantic subgroup OOD
- prompt sensitivity OOD detection
- prompt ensemble CLIP OOD
- VLM OOD reliability

## Questions for each potentially colliding paper

1. Does it evaluate CLIP/VLM-based OOD detection?
2. Does it report semantic subgroup or worst-group metrics?
3. Does it vary prompt templates or measure prompt sensitivity?
4. Does it link prompt variance to OOD failure?
5. Does it propose robust prompt aggregation specifically for worst-group OOD reliability?
6. Does it use MCM, NegLabel, or directly comparable baselines?

## Novelty claim rule

Use one of the following formulations only after evidence review:

- direct gap appears unresolved;
- partially studied, but not under the proposed combination of method / subgroup / prompt analysis;
- already substantially solved, requiring project redesign.

Avoid "nobody has studied this" unless exhaustive evidence supports it.
